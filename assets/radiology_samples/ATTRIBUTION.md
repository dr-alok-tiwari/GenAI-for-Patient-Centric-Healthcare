# Radiology sample image attribution

These 50 raster teaching copies were sourced from Wikimedia Commons. Each copy was resized to fit within 960 × 960 pixels and re-encoded as JPEG; no clinical annotation was added. They are educational examples, not a validated diagnostic dataset or model benchmark.
